# `/regime`(장세 판별) 페이지 가이드

이 문서는 `/regime` 탭(네비게이션의 "장세 판별")에 있는 모든 화면 요소와 숫자가
무엇을 의미하는지 쉽게 풀어서 설명합니다. 개발자가 아니어도 이해할 수 있게
썼습니다.

---

## 이 페이지가 하는 일 (한 줄 요약)

**"지금 이 코인 시장이 5가지 상태(급등/상승/횡보/하락/급락) 중 어디에 있는지"를
AI(머신러닝) 모델이 추측해서 보여주는 화면입니다.**

주식/코인 시장은 항상 "쭉 오르기만" 하거나 "쭉 내리기만" 하지 않고, 어떤 때는
방향 없이 왔다 갔다 하고(횡보), 어떤 때는 급하게 움직입니다(급등/급락). 이
"지금 시장이 어떤 국면(장세)인가"를 자동으로 분류해주는 게 이 페이지의 목적입니다.

---

## 1. 코인 선택 (맨 위 카드)

- **코인 선택**: 어떤 코인의 예측을 볼지 버튼으로 고릅니다. "봉"(캔들, candle)은
  일정 시간 동안의 시가/고가/저가/종가를 하나로 묶은 단위인데, 이 ML 모델은
  **1시간봉 하나로 고정**되어 있어서 따로 봉 주기를 고르는 화면은 없습니다.

⚠️ **제약 사항**: 코드 상으로 이 ML 모델은 최대 14개 코인(BTC/ETH/XRP/SOL/
DOGE/LINK/ADA/XLM/TRX/TRUMP/BCH/BSV/QTUM/ALGO)까지 지원하도록 되어 있지만,
**실제로 지금 라이브 서버에 배포된 모델 하나가 그 14개를 전부 학습했다는 뜻은
아닙니다.** 학습·배포는 그때그때 이뤄지기 때문에, 배포된 모델이 실제로 커버하는
코인 수는 더 적을 수 있습니다. 배포된 모델이 학습하지 않은 코인을 고르면 "ML
현재예측" 카드에 "현재 배포된 모델은 (실제로 학습된 코인 목록)로만 학습되어
있습니다. 재학습 후 배포하면 새 마켓이 반영됩니다." 같은 안내가 뜨고 예측은
나오지 않습니다 — 즉 화면이 그 코인 버튼을 보여준다고 해서 항상 예측이 나온다고
보장하지는 않으며, 실제로 지원되는지는 눌러서 확인해야 합니다.

---

## 2. "ML 현재예측" 카드

### 예측 카테고리 (예: "횡보", "완만상승")

지금 시장이 5개 상태 중 AI가 가장 유력하다고 본 것 하나입니다:

| 카테고리 | 의미 |
|---|---|
| 급상승 | 짧은 시간에 크게 오르는 중 |
| 완만상승 | 천천히, 완만하게 오르는 중 |
| 횡보 | 뚜렷한 방향 없이 왔다갔다 |
| 완만하락 | 천천히, 완만하게 내리는 중 |
| 급하락 | 짧은 시간에 크게 떨어지는 중 |

실제로는 시장이 "횡보"인 경우가 압도적으로 많습니다(아래 분포 참고). 급등/급락은
드물게 일어나는 예외적인 상황입니다.

### 확신도 (%)

AI가 방금 고른 카테고리를 "얼마나 자신 있어 하는지"입니다. 예를 들어 확신도
40%라는 건 "5개 중 횡보가 제일 유력하긴 한데, 그렇게 확신하지는 않는다"는
뜻입니다(5개 중 아무거나 찍어도 평균 20%는 나오니, 40%는 그보다는 확신 있는
편입니다).

### 카테고리별 확률 막대

확신도 하나만 보여주는 대신, AI가 5개 카테고리 각각에 대해 "이거일 확률이
몇 %다"라고 계산한 값 전체를 막대그래프로 보여줍니다. 5개를 다 더하면 100%가
됩니다. 막대가 한 쪽으로 뚜렷하게 몰려있으면 AI가 확신하는 것이고, 5개가 고르게
퍼져 있으면 AI도 잘 모르겠다는 뜻입니다.

### 하단의 작은 안내 문구 (봉 시각 / 모델 학습 시각 / fold)

- **봉 시각**: 이 예측이 어느 시점의 캔들 데이터를 기준으로 계산된 것인지.
- **모델 학습 시각**: 지금 쓰이고 있는 AI 모델을 언제 학습시켰는지(오래된
  모델일수록 최근 시장 상황을 잘 반영 못 할 수 있습니다).
- **fold**: 아래 "모델 성능" 표에서 어떤 검증 구간(fold)의 모델을 실제로 쓰고
  있는지 표시(자세한 의미는 바로 아래 참고).

### 모델 성능

AI 모델이 "실제로 얼마나 잘 맞히는지"를 보여주는 부분입니다. 여기 나오는 숫자들이
가장 헷갈리기 쉬운 개념이라 자세히 설명합니다.

#### fold / train / test 표

AI 모델을 만들 때, 전체 기간(예: 2024년~지금)을 여러 구간으로 나눠서 "앞부분
데이터로 공부시키고 → 뒷부분 데이터로 시험 본다"를 여러 번 반복합니다. 이걸
**워크포워드(walk-forward) 검증**이라고 부릅니다. 마치 "1~9월 데이터로 공부시킨
후 10월 데이터로 시험 보고, 그다음엔 1~10월로 공부시킨 후 11월로 시험 보고..."를
반복하는 것과 같습니다 — 항상 "과거로 공부해서 미래를 맞히는지"만 확인하고,
답을 미리 알고 있는 미래 데이터로 공부시키는 반칙은 하지 않습니다.

- **fold**: 몇 번째 "공부-시험" 라운드인지 번호.
- **train**: 그 라운드에서 공부(학습)에 쓴 데이터 개수(봉 개수).
- **test**: 그 라운드에서 시험(검증)에 쓴 데이터 개수.
- **상관계수**: 그 라운드의 시험 결과 — 바로 아래서 설명합니다.

#### 풀링 상관계수 (가장 중요한 숫자)

**"AI가 예측한 방향과 실제로 일어난 결과가 얼마나 같이 움직였는가"**를 나타내는
숫자입니다. 이 프로젝트에서는 AI가 낸 확률들을 점수 하나로 환산한 값(예: 급상승
쪽에 가까울수록 +, 급하락 쪽에 가까울수록 -)과, 그 이후 실제로 시장이 얼마나
움직였는지를 비교해서 계산합니다.

- **+1에 가까울수록**: AI가 "오를 것 같다"고 하면 실제로 올랐고, "내릴 것 같다"고
  하면 실제로 내렸다 → 예측이 잘 맞는다는 뜻.
- **0에 가까울수록**: AI의 예측과 실제 결과 사이에 아무 관련이 없다 → 예측이
  거의 도움이 안 된다는 뜻(동전 던지기와 비슷).
- **-1에 가까울수록**: AI가 "오를 것 같다"고 했는데 실제로는 내렸다 → 예측이
  거꾸로 맞는다는(반대로 하면 맞는) 뜻.

지금 이 모델의 상관계수는 대략 **0.05~0.15 사이**로, 0보다는 크지만(아예
무의미하진 않지만) 아주 강한 예측력은 아닙니다. "약하지만 의미 있는 신호"
정도로 이해하면 됩니다.

**"풀링(pooled)"**이란 여러 fold의 시험 결과를 한 번에 모두 모아서 계산했다는
뜻입니다(fold별로 따로 계산한 상관계수를 평균 내는 건 통계적으로 올바르지 않아서,
항상 전체를 한 번에 모아 다시 계산합니다).

#### 카테고리별 hit-rate (적중률)

"AI가 특정 카테고리라고 예측했을 때, 실제로 그 카테고리가 맞았던 비율"입니다.
예를 들어 "횡보: 620/900 적중 (68.9%)"라면, AI가 "횡보다"라고 예측한 900번 중
620번은 실제로도 횡보였다는 뜻입니다.

- 상관계수와 다른 점: 상관계수는 "얼마나 강하게 맞았는지(확률 분포 전체)"까지
  보는 지표고, hit-rate는 "맞았다/틀렸다"만 단순하게 세는 지표입니다.
- 참고: "횡보"는 원래 실제로도 가장 자주 일어나는 상태라서(전체의 60%~70%
  정도), 횡보의 hit-rate가 자연스럽게 높게 나오는 경향이 있습니다. 반대로
  "급상승"/"급하락"처럼 드문 카테고리는 표본이 적어서 hit-rate가 불안정하거나
  낮게 나올 수 있습니다.

## 3. ML 재학습 관리자 패널

⚠️ 이 패널은 평소에는 화면에 보이지 않습니다. 로컬 개발 환경에서만 켤 수 있는
관리자 전용 기능이고, AWS 라이브 서버에서는 안전을 위해 절대 켜지지 않습니다
(이유: 재학습이 컴퓨터 자원을 꽤 쓰는 작업이라, 실거래가 돌아가는 서버에서
돌리면 서버가 버벅이거나 죽을 위험이 있기 때문입니다).

### "학습 시작" 버튼

누르면 **최신 시세 데이터까지 포함해서 AI 모델을 처음부터 다시 학습**시킵니다.
- 로컬 컴퓨터에서만 실행됩니다(약 2~3분 정도 걸림).
- 학습 중에는 버튼이 "학습 중..."으로 바뀌고 비활성화됩니다.
- 학습이 끝나면 자동으로 아래 "모델 목록"에 새 모델이 추가됩니다.
- 학습이 실패하면(예: 데이터 부족, 백엔드 재시작 등) 버튼 아래에 실패 사유가
  표시됩니다.

### 모델 목록 (과거 학습 이력)

지금까지 학습시킨 모델들을 최신순으로 보여주는 표입니다.

| 컬럼 | 의미 |
|---|---|
| 학습시각 | 그 모델을 언제 학습시켰는지 |
| 풀링 상관계수 | 위에서 설명한 "예측이 실제와 얼마나 맞는지" 점수(높을수록 좋음) |
| 현재 배포됨 (뱃지) | 지금 AWS 라이브 서버에 올라가 있는 모델이라는 표시 |
| 배포 버튼 | 그 줄의 모델을 라이브 서버로 올리는 버튼 |

**왜 여러 개가 쌓이나요?**: 학습을 여러 번 하면 그때그때 결과가 달라질 수
있습니다(데이터가 늘어나거나, 최근 시장 상황이 바뀌면 상관계수가 오르내릴 수
있음). 그래서 "이번에 새로 학습한 게 예전 것보다 나은지"를 직접 비교해보고,
더 나은 쪽을 골라서 배포할 수 있게 과거 이력을 전부 남겨둡니다.

### "배포" 버튼

원하는 줄의 "배포"를 누르면 확인 창이 뜨고, 확인하면 **그 모델을 실제 라이브
거래 대시보드가 참조하는 AWS 서버로 전송**합니다. 이건 "지금 사용 중인 예측
모델을 바꾸는" 실질적인 변경이라 확인 절차를 한 번 거칩니다.

- **"현재 배포됨" 뱃지가 있는 모델도 다시 배포할 수 있습니다** — 이 뱃지는
  참고용 표시일 뿐, 실제로 지금 서버에 뭐가 올라가 있는지를 100% 보장하는 건
  아니기 때문입니다(예: 누군가 서버에서 수동으로 다른 걸로 바꿨다면 이 뱃지와
  실제 상태가 어긋날 수 있음).
- 학습만 하고 배포는 안 하는 것도 가능합니다 — 새로 학습한 모델의 상관계수가
  이전보다 안 좋으면, 배포하지 않고 그냥 예전 모델을 계속 쓰면 됩니다.

## 자주 헷갈리는 것 정리

**Q. 학습(training)이랑 배포(deploy)는 뭐가 다른가요?**
학습 = "최신 데이터로 AI를 다시 공부시켜서 새 모델 파일을 만드는 것"(로컬에서만).
배포 = "그렇게 만들어진 모델 파일 중 하나를 골라서 실제 라이브 서버로
전송하는 것". 학습한다고 자동으로 라이브에 반영되지 않습니다 — 사람이 결과를
보고 괜찮다 싶을 때만 배포합니다.

**Q. 상관계수랑 hit-rate 중 뭘 더 믿어야 하나요?**
상관계수가 좀 더 전체적인 그림(방향과 강도)을 보여주고, hit-rate는 카테고리별로
단순하게 "맞았다/틀렸다"만 봅니다. 두 지표가 같은 방향으로 좋아지면(둘 다
올랐으면) 더 신뢰할 수 있는 개선입니다.

**Q. 새로 학습하면 항상 더 좋아지나요?**
아닙니다. 시장 상황 자체가 예측하기 어려워지면 아무리 다시 학습해도 상관계수가
비슷하거나 오히려 떨어질 수 있습니다. 그래서 배포 전에 꼭 새 모델의 성능
지표를 확인하고 판단하는 절차를 두고 있습니다.

**Q. 왜 "횡보"가 이렇게 자주 나오나요?**
실제 시장 자체가 방향 없이 왔다갔다 하는 시간이 절대적으로 많기 때문입니다
(급등/급락처럼 극적인 순간은 흔치 않습니다). 이건 모델의 문제가 아니라 시장의
원래 성질입니다.

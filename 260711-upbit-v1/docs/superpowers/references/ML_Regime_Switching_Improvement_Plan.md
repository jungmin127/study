# ML 기반 동적 장세 판별 및 매매 전략 전환 시스템 개선 보고서

## 1. 현재 모델 성능 진단 및 해석

### ① 예측력 수준 (낮은 상관계수)
* **Test Set 상관계수**: Fold별 0.075 ~ 0.145, 전체 폴링 상관계수 **0.077**
* **해석**: Actual label과 Predicted label 간의 선형 관계가 거의 없거나 매우 약함을 의미하며, 예측의 신뢰도가 낮습니다.

### ② 클래스 편향 (횡보 몰아주기 현상)
* **카테고리별 Hit-rate (전체 fold 합산)**:
  * 횡보: **68.0%**
  * 완만하락: 18.8%
  * 완만상승: 14.3%
  * 급하락: 5.2%
  * 급상승: 1.4%
* **문제점**: 금융 시계열 데이터 특유의 클래스 불균형으로 인해 모델이 손실(Loss)을 줄이려 가장 빈도가 높은 '횡보'로 예측을 몰아주는 편향에 빠졌습니다.
* **결과적 영향**: 실전 매매 시 대부분의 시간 동안 '횡보용 전략'만 실행되어, 장세에 따른 동적 전략 전환 의도가 작동하지 않게 됩니다.

## 2. 문제 정의(Problem Formulation) 재정의 방안

### ① 5단계 분류 → 2~3단계 단순화 (차원 축소)
* 5개 클래스(급상승, 완만상승, 횡보, 완만하락, 급하락)의 경계는 비선형적이고 모호합니다.
* **3단계 단순화**: `상승(Bull)` / `횡보(Neutral)` / `하락(Bear)`
* **2단계 Binary 분류**: `추세장(Trend)` vs `비추세장(Range)`
  * 전략 전환의 핵심 목적이 **"추세 추종 전략을 켤 것인가, 박스권/역매매 전략을 켤 것인가"**에 있으므로, [추세/비추세] 선별 후 세부 방향을 결정하는 2-Step 방식이 정확도가 훨씬 높습니다.

### ② Sample Weighting & Loss Function 조정
* 5단계 분류를 유지할 경우, 클래스 불균형 해소가 필수적입니다.
* **Focal Loss** 또는 **Class Weighting**을 도입하여 급상승/급하락 등 소수 클래스 오예측 시 가중 벌점을 부여합니다.
* Evaluation Metric을 단순 Accuracy/Hit-rate에서 **Macro F1-Score** 또는 **Weighted Kappa**로 변경합니다.

## 3. Dynamic Strategy Switching 최적 아키텍처 제안

### 제안 A. 전략별 기대 수익률 직접 예측 (Meta-Labeling / Direct Multi-Output)
* **개념**: "장세 정의 → 전략 매칭"의 이중 오차(Double Error)를 제거하고, 각 전략의 기대 성과를 직접 예측합니다.
* **구현**:
  * 모델 출력값: `[전략 A 기대수익률, 전략 B 기대수익률, ..., 전략 E 기대수익률]`
  * 가장 높은 기대수익률(또는 Risk-Adjusted Return)을 가리키는 전략 선택.
  * 모든 전략의 기대치가 음수(-)일 경우 **현금 보유(No Position)** 관망.

### 제안 B. Rule-Based Regime Filter + ML (하이브리드 2-Step)
* **개념**: 명확한 기술적 지표로 큰 틀의 시장 구조를 1차 필터링하고, ML이 세부 신호를 2차 검증합니다.
* **구현**:
  1. **1차 Macro Filter (Rule-Based)**: SMA 200, ADX, ATR 등을 활용해 `[추세장 vs 비추세장]`, `[고변동 vs 저변동]` 구분.
  2. **2차 Micro Classifier (ML)**: 해당 환경 내에서만 세부 진입/반전 가능성 예측.
* **장점**: ML 탐색 공간(Search Space) 축소, 신호 대 잡음비(SNR) 상승, 치명적 오예측 방지.

### 제안 C. HMM(Hidden Markov Model) 기반 Unsupervised Regime Tracking
* **개념**: 수동 라벨링 대신, 시장의 비가시적 상태(Hidden State)를 통계적 클러스터링으로 추적합니다.
* **구현**:
  1. 수익률, ATR, 거래량을 입력으로 **Gaussian HMM** 학습.
  2. 과거 데이터를 통계적 특성에 따라 3~4개 State(예: 저변동 상승, 고변동 하락, 박스권)로 자동 클러스터링.
  3. State별 과거 우수 백테스트 전략 1:1 매핑.
  4. 실시간 데이터 입력 시 각 State에 속할 확률(Probabilities)을 정밀 산출하여 전략 전환.

## 4. 백테스트 및 실행 고도화 Tip

1. **Triple Barrier Method (라벨링 개편)**:
   * 단순히 N시간 후 수익률 기반 라벨링 대신, 상단 익절선 / 하단 손절선 / 만기 시간을 설정하여 먼저 터치하는 지점으로 라벨링(Marcos López de Prado 방식).
2. **Hysteresis (전략 전환 완충 지대)**:
   * 잦은 전략 교체로 인한 수수료/슬리피지 방지를 위해, 예측 확률의 이동평균을 적용하거나 확신도 Threshold(예: 60% 이상 시에만 Switch) 적용.
